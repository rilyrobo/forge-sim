# Story Manager

A React + Vite application for managing characters, relationships, timelines, factions, secrets, and evolving narratives.

Story Manager is designed for writers, game masters, worldbuilders, and storytellers who need more than a collection of notes. Instead of treating characters as isolated entries, Story Manager helps track how people, organizations, and events interact over time.

Whether you're building a tabletop RPG campaign, a novel series, a video game setting, or a collaborative storytelling project, Story Manager provides tools to organize complex worlds and the relationships that drive them.

---

# Features

## Character Management

Create and manage detailed character profiles.

Track:

* Names and aliases
* Roles and occupations
* Biographies
* Motivations
* Goals
* Status information
* Custom fields
* Notes

Characters can represent:

* Player characters
* NPCs
* Historical figures
* Organizations
* Factions
* Creatures
* Any narrative entity

---

## Relationship Tracking

Create explicit connections between characters and groups.

Examples include:

* Friendship
* Rivalry
* Family
* Alliance
* Mentorship
* Distrust
* Political relationships

Relationship strength and notes can be tracked over time.

---

## Interactive Relationship Graph

Visualize the social structure of your world.

Features:

* Character nodes
* Relationship connections
* Cluster identification
* Faction visualization
* Network exploration

Useful for understanding complex social dynamics at a glance.

---

## Timeline Management

Track important events throughout your story or campaign.

Examples:

* Historical events
* Character milestones
* Session summaries
* Political changes
* Discoveries
* Major conflicts

Events can be organized chronologically and linked to relevant characters.

---

## Secret and Knowledge Tracking

Store information that should not be immediately visible to all participants.

Perfect for tracking:

* Hidden motivations
* Plot twists
* Secret identities
* Unrevealed events
* Conspiracies
* Character knowledge

Control when information becomes visible as the story develops.

---

## Faction and Organization Support

Manage groups, organizations, kingdoms, guilds, religions, corporations, or political movements.

Track:

* Membership
* Alliances
* Rivalries
* Influence
* Internal conflicts

---

## Session and Story Notes

Maintain records of:

* Campaign sessions
* Writing progress
* Story arcs
* Character development
* Narrative changes

Keep all relevant information connected to the people and events involved.

---

# Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

# Philosophy

Stories are built from relationships, choices, and consequences.

Story Manager is designed to help creators keep track of those connections, making it easier to manage complex narratives without losing sight of the characters that bring them to life.
